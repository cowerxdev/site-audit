# Contributing

Issues and pull requests are welcome at https://github.com/cowerxdev/site-audit. Describe the page pattern or user problem, the expected result, and a small reproducible example. Do not include private pages, credentials, or visitor data.

Use Node.js 20 or newer. Install dependencies with `npm install`, run `npm test`, and run `npm run test:pack` before submitting a change. Add a synthetic fixture for a new check or a regression. Keep output evidence understandable to someone reviewing a website, and document changes that affect scores in `CHANGELOG.md`.
